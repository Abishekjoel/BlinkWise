# 👁️ BlinkWise

**BlinkWise** is an AI-powered web application designed to assist in the early detection of **Diabetic Retinopathy** from retinal fundus images. By leveraging deep learning and computer vision, BlinkWise analyzes retinal scans and predicts the severity of diabetic retinopathy, helping support timely diagnosis and treatment.

> **"See Beyond the Blink."**

---

## 🌟 Features

* 🔍 AI-powered diabetic retinopathy detection
* 📤 Upload retinal fundus images for analysis
* 📊 Predict disease severity
* ⚡ Fast and intuitive user interface
* 📱 Responsive design for desktop and mobile
* 📈 Displays prediction results with confidence score
* 🩺 Supports early screening and awareness

---

## 🧠 How It Works

1. Upload a retinal fundus image.
2. The image is preprocessed.
3. A trained deep learning model analyzes the image.
4. BlinkWise predicts the stage of diabetic retinopathy.
5. The prediction and confidence score are displayed.
